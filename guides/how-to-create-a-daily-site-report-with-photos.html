How to create a daily site report with photos

Updated 5 October 2026 · 5 min read

A daily site report that is quick to produce and easy to read protects everyone: the contractor, the client and the crew.

What a daily report covers

  • Progress by area, from consistent vantage points.
  • Any defects, delays or issues, with photos.
  • Deliveries, plant and materials on site.
  • Safety and compliance observations.
  • Weather and anything that affects the work.

The routine

  1. Walk the site in the same order each day.
  2. Shoot the same sequences so change is obvious.
  3. Add a one line note to each key shot.
  4. Export a dated PDF before you leave.

Keeping jobs separate

Group photos per project so reports never mix. StampCam uses hashtags such as #NorthWing to group shots automatically.

Questions

  • How long should a daily report take? With a fixed routine, the photos are taken during the walk and the PDF generates on site in a minute.
  • Should each photo be timestamped? Yes. It ties the report to the day and stops any dispute about when work happened.
